\section*{Methods}

\subsection*{Source data and study design}
All data come from NASA Open Science Data Repository study OSD-528 (GLDS-528)\cite{osd528data}, deposited by Clary and colleagues\cite{clary2022development}. According to the OSDR study description, \textit{M.~marinum} expressing red fluorescent protein was grown in biofilm-promoting medium in flaskettes holding a piece of polydimethylsiloxane (PDMS) membrane. Flaskettes were attached to an RPM~2.0 or to a lab-designed 3D clinostat in the same incubator, or placed on the shelf beside them as the static 1g control, for 4~days at 31\,$^\circ$C. RNA was prepared from the bacteria in suspension. The transcriptomes therefore describe planktonic cells grown alongside the membrane, not the membrane biofilm. Three libraries per condition were deposited as paired-end FASTQ files (\nSamplesDeposited{} samples, 18 files). We downloaded every file through the OSDR file API and checked it against the deposited md5 list before use.

\subsection*{The RFPRPM4 deposit defect}
The deposited R1 and R2 files of sample RFPRPM4 each begin with the complete corresponding file of sample RFPRPM41: the md5 of the first \rpmFourPrefixBytesRone{} bytes of RFPRPM4~R1 equals the deposited md5 of RFPRPM41~R1, and likewise for R2. A second gzip stream follows in each file, holding \rpmFourPairs{} read pairs. These reads come from the same sequencing run but carry a library index used by no other sample. Read from the start, RFPRPM4 therefore duplicates RFPRPM41. We split off the second library and treat it as an \emph{inferred} RFPRPM4: it is excluded from the primary analysis, which uses \nGround{} ground, \nClino{} clinostat and \nRpm{} RPM samples, and included only in a sensitivity analysis. The OSDR curators have not yet been asked to confirm this assignment.

\subsection*{Quantification}
Reads were quantified with kallisto \kallistoVersion{}\cite{bray2016near} in paired-end mode against the \textit{M.~marinum} strain M RefSeq assembly GCF\_000018345.1\cite{stinear2008insights}, whose md5 was checked against NCBI. The index contained all \nCdsIndex{} annotated coding sequences (CDS) plus the genome's \nNcrnaDecoys{} rRNA, tRNA and other non-coding RNA genes as decoys. Library strandedness was inferred by pseudoaligning 200{,}000 read pairs in each orientation; the libraries are \strandedness{}-stranded and were quantified as such. Between \pctRrnaMin{}\% and \pctRrnaMax{}\% of read pairs were assigned to rRNA, which suggests little or no rRNA depletion. CDS received \pctCdsMin{}--\pctCdsMax{}\%, about \cdsPairsPrimaryMinK{}{,}000--\cdsPairsPrimaryMaxK{}{,}000 read pairs per primary sample. Only CDS rows enter the count matrix (Supplementary Table~S1).

\subsection*{Differential expression}
Estimated counts were rounded and analysed with DESeq2 \deseqVersion{}\cite{love2014moderated} using the design $\sim$\,condition (ground, clinostat, RPM). Genes with at least 10 counts in at least 2 samples were kept (\nGenesTested{} of \nGenesInput{} non-pseudogene CDS). We tested clinostat vs ground, RPM vs ground and clinostat vs RPM with Wald tests and Benjamini--Hochberg (BH) correction, calling a gene differentially expressed (DEG) at FDR $<0.05$. Fold changes are reported both as maximum-likelihood estimates and shrunk with apeglm \apeglmVersion{}\cite{zhu2019heavy}. The shared simulated-microgravity response is the set of genes that are DEGs under both simulators with the same sign. For the principal component analysis (PCA), we used the variance-stabilised transform (blind to design) and the \pcaGenes{} most variable genes. The whole analysis was repeated with the inferred RFPRPM4 library included (sensitivity analysis).

\subsection*{Co-expression network}
We built a signed weighted gene co-expression network with WGCNA \wgcnaVersion{}\cite{langfelder2008wgcna} from the variance-stabilised expression of the \nPrimary{} primary samples. The soft-thresholding power was the smallest that gave a signed scale-free fit $R^2\ge0.8$ (power \wgcnaPower{}, $R^2=\wgcnaRsq$). Modules were detected with a minimum size of 30 genes and merged at a cut height of 0.25. Module eigengenes were correlated with three binary traits (simulated microgravity, clinostat, RPM). Student p-values were BH-corrected across all \nModuleTraitTests{} module--trait tests. With eight samples every correlation rests on eight points, so the network results are exploratory.

\subsection*{Gene Ontology over-representation}
GO annotations for \textit{M.~marinum} strain M were taken from UniProtKB (reference proteome UP000001190, release \uniprotRelease{}) and mapped to RefSeq locus tags through the GenBank \texttt{old\_locus\_tag} qualifiers. They were propagated up the \texttt{is\_a} and \texttt{part\_of} relations of go-basic (release \goRelease{}). Of the \goTestedGenes{} genes tested for differential expression, \goAnnotatedGenes{} (\goAnnotatedPct\%) have at least one annotation, and \goIeaPct\% of the annotations used are electronic (IEA), so the results describe predicted function. For each DEG set (up and down per contrast, and the shared response) and each WGCNA module, we ran a one-sided hypergeometric test for every GO term with 5--500 annotated genes in the universe. The universe was the annotated tested genes, taken separately for biological process, molecular function and cellular component. P-values were BH-corrected within each ontology and gene set. The test treats genes as independent; operons and nested GO terms make neighbouring results correlated.

\subsection*{Software and reproducibility}
Every step is a script in the repository (\texttt{analysis/00}--\texttt{09}), and \texttt{make all} reruns the pipeline from the raw reads. Every number quoted in this manuscript is written into \texttt{manuscript/chapters/numbers.tex} by \texttt{analysis/09\_manuscript\_numbers.py} from the output files, and every figure is drawn from those outputs by \texttt{analysis/06\_generate\_figures.py}.
