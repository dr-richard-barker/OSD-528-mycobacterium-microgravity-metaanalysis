\section*{Data availability}
Raw reads are available from the NASA Open Science Data Repository as study OSD-528 (GLDS-528; DOI \href{https://doi.org/10.26030/r3re-fd65}{10.26030/r3re-fd65}). The RFPRPM4 files in that deposit contain the RFPRPM41 files followed by a second library (Methods). All processed data (count matrices, differential expression, network, enrichment, classification and metabolic-subsystem tables) are in the repository below, under \texttt{data/processed/} and \texttt{results\_tables/}. The repository has no archival (Zenodo) DOI yet.

\section*{Code availability}
All analysis code is at \url{https://github.com/dr-richard-barker/OSD-528-mycobacterium-microgravity-metaanalysis} under the MIT licence. \texttt{make all} reproduces every result, table, figure and number in this manuscript from the raw OSDR reads.
