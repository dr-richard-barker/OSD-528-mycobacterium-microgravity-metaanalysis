# A shared transcriptional response of *Mycobacterium marinum* to two microgravity simulators: a re-analysis of NASA OSDR study OSD-528

[![NASA OSDR](https://img.shields.io/badge/NASA%20OSDR-OSD--528-0B3D91.svg)](https://osdr.nasa.gov/bio/repo/data/studies/OSD-528)
[![Code: MIT](https://img.shields.io/badge/code-MIT-blue.svg)](LICENSE)
[![Zenodo](https://img.shields.io/badge/Zenodo-not%20yet%20deposited-lightgrey.svg)](DATA_PROVENANCE_DECLARATION.md)

An independent re-analysis of the RNA-seq data that Clary and colleagues deposited in NASA's Open Science
Data Repository as study **OSD-528**. Their experiment grew *M. marinum* for 4 days at 31 °C on a
lab-built 3D clinostat, on a commercial RPM 2.0, or on the incubator shelf beside them (static 1g), and
sequenced the bacteria in suspension. This repository re-quantifies every deposited read, compares the two
simulators' transcriptional responses, and keeps every number, table and figure reproducible from the raw
reads.

**Author:** Richard Barker, Collaborative Science Environment Inc., Madison, Wisconsin, USA
([ORCID 0000-0001-5681-9857](https://orcid.org/0000-0001-5681-9857)). The experiment, sequencing and data
deposit are the work of Clary et al. (2022); see [Citation](#citation).

> [!IMPORTANT]
> Versions of this repository before October 2026 were built first on synthetic data and then on a
> 60 MB slice of each read file, with hard-coded figures, enrichment values and a fake "TabPFN" model.
> They have been replaced. [`DATA_PROVENANCE_DECLARATION.md`](DATA_PROVENANCE_DECLARATION.md) records the
> history and how every current result is produced.

## Key results

<!-- numbers:start -->
Generated by `analysis/09_manuscript_numbers.py` from `data/processed/`; do not edit by hand.

- **Reads:** 14.0–16.3 million read pairs per library, of which 88.2–95.0% are rRNA and 1.0–5.0% protein-coding.
- **Samples:** primary analysis 3 ground, 3 clinostat and 2 RPM; the inferred RFPRPM4 library is used only in the sensitivity analysis.
- **Differential expression** (DESeq2, FDR < 0.05, 3,968 genes tested): 619 genes under the clinostat (187 up, 432 down) and 706 under the RPM (209 up, 497 down).
- **Shared response:** 533 DEGs under both simulators, 533 in the same direction; fold changes correlate at Spearman ρ = 0.92. Clinostat vs RPM directly: 0 DEGs (low power, RPM n = 2).
- **Sensitivity analysis** with the inferred RFPRPM4: 859 RPM DEGs; fold changes correlate with the primary analysis at r = 0.98.
- **GO** (electronic annotations, 71% of tested genes annotated): shared up genes are enriched for the extracellular region (15 Mce-family genes) and NADH dehydrogenase activity; shared down genes for transcription factor activity and the response to heat.
- **WGCNA:** 20 modules; 2 of 63 module–trait tests pass FDR < 0.05 (turquoise r = -0.93, blue r = 0.92, with simulated microgravity).
- **Classification** (leave-one-out, exact permutation tests): microgravity vs 1g, every model 6/8 correct (balanced-accuracy p = 0.089–0.21); three classes, TabPFN 6/8 (p = 0.014) vs logistic regression 3/8, but not robust to adding RFPRPM4 (4/9, p = 0.17).
- **KEGG-mapped metabolic subsystems:** 28 reactions with KEGG-supported genes (of the old model's 32 reactions, 24 were on the wrong gene). Only cellular respiration is enriched for DEGs, under the RPM (10/19 genes, all up; FDR 0.0047); mycolic acid / FAS-II shows 0/15 DEGs.
- **Context:** 102 microbial spaceflight or simulated-microgravity studies in OSDR (85 spaceflight, 17 ground simulation; Table S16). Studies pairing an RPM with a 3D clinostat: OSD-528.

## The RFPRPM4 deposit defect

The deposited RFPRPM4 R1 and R2 files each contain the complete RFPRPM41 file followed by a second library
with a different index. Read from the start, "RFPRPM4" duplicates RFPRPM41, so the RPM group really has two
independent samples. `analysis/00_quantify_real_osdr_rnaseq.py` proves this by hashing and splits the
files. The second library is used only in a sensitivity analysis until the depositors confirm it is the
real RFPRPM4. A draft report to the OSDR curators, not yet sent, is in
[`docs/OSDR_RFPRPM4_deposit_report.md`](docs/OSDR_RFPRPM4_deposit_report.md).

## Reproducing the analysis

Requirements:
- **Python 3** with numpy, pandas, scipy, matplotlib and requests (`requirements.txt`).
- **R** with DESeq2, apeglm, WGCNA and jsonlite.
- **kallisto** 0.52 and curl.
- For the classification step, a separate environment: `make ml-env` installs `requirements-ml.txt` into `.venv-ml/`.
- To build the manuscript: pdflatex, bibtex and pandoc.

```bash
make all          # every step, from the raw OSDR reads to the manuscript
make figures      # one step at a time: quantify, de, wgcna, ml, go, kegg, osdr, figures, package, numbers, manuscript
```

The first `make quantify` downloads the 18 raw FASTQs from OSDR and checks each against the deposited md5
list. Later runs reuse the verified files.
